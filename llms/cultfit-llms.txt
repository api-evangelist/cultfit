# Cult.fit

> Cult.fit (Curefit / cure.fit, operated by Diverse Retails Private Limited) is an Indian health
> and fitness company offering a connected consumer experience across group fitness classes, gyms,
> at-home workouts, mental well-being and meditation, healthy food, and diagnostics. Its flagship
> products include CultPass gym and class memberships, sport and fitness centers, live and on-demand
> digital workouts, and the cult.fit and cure.fit mobile and web apps.

Important: Cult.fit does NOT publish a public developer API program. There is no developer portal,
no API reference, no OpenAPI/AsyncAPI/GraphQL contract, no SDK, and no public API credentials. The
`api.cure.fit` host that backs the mobile and web apps is a private first-party backend; the public
web property's robots.txt explicitly disallows `/api/`. Any third-party "Cult.fit API" client you
encounter is an unofficial reverse-engineering of that private app backend, not a supported product.

## Security
- [Security and bug bounty](https://www.cult.fit/security): Public vulnerability disclosure program
  with Gold/Silver/Bronze/Thanks reward tiers. Reports go to security@cult.fit. In-scope domains are
  *.cult.fit, *.curefit.co, *.cultsport.com, and *.curefit.com.
- No security.txt is served at /.well-known/security.txt on any Cult.fit host (404 on all probed).
- No trust center and no named certifications (ISO 27001, SOC 2, PCI DSS, HIPAA) are published.
